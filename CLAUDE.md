# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Gappu is a voice companion web app for a young child ("Tosu") on an iPad. The child taps a button, speaks in Hindi/English/Hinglish, and a pretend baby-elephant friend answers aloud. Safety rules for a preschooler are the core design constraint — every change to prompts, output handling, or memory must preserve them (see "Safety invariants" below).

A handful of files, no build step, no dependencies, no tests:

- `public/index.html` — the entire client (HTML/CSS/JS in one file). Served as a static asset. Layers, back to front: `#scene` (sun/moon/stars/clouds, time-of-day via `body[data-time]`), `#stage` (bubble, SVG face, hill, button), `#fg` (flowers, click-through). Face expressions are pure CSS keyed on `body[data-mood]` and state classes (`listening`, `thinking`, `talking`, `sleepy`, `sleeping`, `giggle`); the mic level is exposed as `--level` on `#talk`. Sound cues are a tiny WebAudio synth (`tone()`), toggled by `settings.sounds`.
- `public/sw.js`, `manifest.webmanifest`, `icon-*.png` — PWA shell. The page is network-first so updates arrive on next open; icons/fonts are cache-first. Icons are generated by a PIL script (see git history / regenerate by drawing at 1024 and downscaling).
- `src/worker.js` — the Cloudflare Worker. Owns the Gemini API key, the system prompt, output sanitization, and entitlement policy (`resolveFamily` → 401, `entitlementError` → 402/429).
- `src/entitlements.js` — self-host only (Node 22+, `node:sqlite`): `data/gappu.db` with `families` (plan, status, cap, invited `email`, bound `google_sub`), `devices` (sha256 of each iPad's token), `usage_months`, `events`; schema v2 via `PRAGMA user_version`, `migrate()` upgrades v1 in one transaction. Exposed to the worker as `env.ENTITLEMENTS`. Counts only, never content.
- `bin/gappu-admin.js` — provisioning CLI (`create --email|set-email|devices|revoke-device|renew|suspend|resume|revoke|set-cap|list|usage|backup`). Changes apply on the next request; there is no cache.
- `wrangler.toml` — Cloudflare config. `[assets]` serves `public/` and binds it as `ASSETS`.

## Local testing

`npx wrangler dev` reads secrets from `.dev.vars` (`GEMINI_API_KEY`, `APP_TOKEN`; never commit it). It hot-reloads `worker.js` and `index.html` but **not** `.dev.vars` — restart after editing it. Open http://localhost:8787 in Chrome on the laptop; `localhost` is a secure context so the mic works. On the iPad the page must be HTTPS (`cloudflared tunnel --url http://localhost:8787` is the easy route). Laptop TTS voices sound robotic; that is the OS, not the app — the iPad with Enhanced Lekha is the real target.

To exercise the pipeline without a mic, generate 16 kHz mono WAVs (e.g. Windows `System.Speech`), base64 them, and `POST /api/chat` with the `x-app-token` header — same path as the pink button.

## Roadmap

`PLAN.md` is the plan of record for turning Gappu into a subscription: standalone entitlement layer (SQLite `families`/`usage_months`, token → plan/status/cap check behind `resolveFamily()`), EdunodeX as a channel via a thin provisioning API, and graduation to XV-shell-issued API keys only on a stated trigger. Read it before adding accounts, billing, or multi-tenancy; don't wire Gappu into EdunodeX's per-school tenancy or the XV shell ahead of that plan.

## Self-hosting (current production)

Gappu is live at **https://gappu.in1.xentovia.ai**, self-hosted on the `e2en-edutrack` box instead of Cloudflare. `server.js` is a ~90-line Node adapter that hands each request to `worker.fetch(request, env)` unchanged and implements `env.ASSETS` as a static server for `public/`; there is no separate code path, so Cloudflare deploys keep working from the same repo.

On the server:
- Code: `~/projects/gappu` (git checkout, see Redeploy below). Secrets in `~/projects/gappu/.env` (`GEMINI_API_KEY`, `APP_TOKEN`, `PORT=10800`, `HOST=172.18.0.1`).
- Process: `gappu.service` (systemd, user `santosh`, `Restart=always`), running **Node 24 LTS from `/opt/node-24`** (symlink to the official tarball, checksum-verified; `/usr/bin/node` is v18 and lacks `node:sqlite` — leave it for whatever else uses it). `MemoryMax=1536M`, `LimitNOFILE=65536`. Node 24 is supported until 2028-04-30; to upgrade, unpack the new tarball to `/opt/node-vX`, re-point the symlink, re-run the tests, restart. Never `pkill -f server.js` on this box — it kills production; kill scratch servers by PID. `sudo systemctl restart gappu` after copying new code; `journalctl -u gappu -f` for logs.
- Families: `data/gappu.db` (mode 600, untracked). `GAPPU_DB=off` falls back to the single `APP_TOKEN`; with the DB on, `server.js` withholds `APP_TOKEN` from the worker so a wiring bug fails closed. Nightly `gappu-admin backup` cron at 21:15 UTC → `~/backups/gappu/` (keeps 14).
- HTTPS: `~/projects/edunodex/extra-sites/gappu.caddy` in the shared `edx2_caddy` container, proxying to `172.18.0.1:10800` (the Docker bridge IP; Gappu binds only there, so it is not reachable from the internet except via Caddy). Reload with `docker exec edx2_caddy caddy reload --config /etc/caddy/Caddyfile` after validating.
- The host is `*.in1.xentovia.ai` on purpose: `*.in1.edunodex.in` uses on-demand TLS whose `ask` callback only approves EdunodeX tenants, and Caddy's automation-policy ordering cannot reliably override it from `extra-sites/`. Don't move it there without adding `gappu` to the backend's `/caddy/check-domain` allowlist.

Redeploy: `~/projects/gappu` on the server is a git checkout of `github.com/santoshray02/gappu` (branch `main`). Development happens there directly: edit → `sudo systemctl restart gappu` → test at the public URL → commit → push. `.env` is untracked and must stay so.

`HANDOFF.md` is the session-to-session handoff: current state, verification commands, next task.

## Commands

All via `npx wrangler` (there is no `package.json`):

```bash
npx wrangler login
npx wrangler secret put GEMINI_API_KEY   # paid-tier Gemini key
npx wrangler secret put APP_TOKEN        # shared secret the iPad sends as x-app-token
npx wrangler deploy                      # deploy worker + static assets
npx wrangler dev                         # local dev server (needs .dev.vars with the two secrets)
npx wrangler tail                        # live logs; use to debug "My brain took a nap" errors
```

Optional var: `GEMINI_MODEL` under `[vars]` in `wrangler.toml` (default `gemini-3.1-flash-lite` in `MODEL_DEFAULT`).

Any change to `src/worker.js` (including the `systemPrompt`) requires a redeploy. Changes to `public/index.html` also go out with `deploy`.

## Architecture

**Request flow:** iPad records mic audio via `AudioContext` → client-side VAD (RMS > `0.025` starts speech; `1500` ms of silence or `15000` ms cap stops it, in `startRecording`) → PCM encoded to 16 kHz WAV, base64'd → `POST /api/chat` with `{audio, history, memories, profile}` and header `x-app-token` → worker builds a Gemini `generateContent` request (previous turns as text, only current turn as inline audio, system prompt with memories injected) → Gemini returns structured JSON per `SCHEMA` → worker `sanitizeOut`s it → client speaks `reply` with `speechSynthesis` using a voice picked by `lang` (`hi`/`en`), logs the turn, and merges `new_facts` into memories.

**Routing in the worker:** `/api/chat` (POST), `/api/me` (GET: `{plan,status,expires_at,used_s,cap_s}`, no PII) and `/api/consent` (POST `{version}` → `events` row `kind='consent'`, version only); everything else falls through to `env.ASSETS.fetch`.

**Sign in with Google (self-host, needs `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET` in `.env`):** the only way a parent signs in. Server-side authorization-code flow (`handleGoogle` in the worker), **not** Google's popup/FedCM button like EdunodeX — popups can't open in an iOS Home Screen app. The iPad makes a random secret S, sends `sha256(S)` as OAuth `state` via `/auth/google/start`, and collects its device token from `POST /auth/google/poll {secret: S}`, so the login completes whichever browser Google returns to. Pending logins live in memory (raw token never on disk, 10-min TTL). The verified email must match an invited family (`gappu-admin create --email`); the first sign-in binds `google_sub`, a different sub is refused. `/auth/google/status` → `{enabled}`; when false (Cloudflare, no client configured) the wizard falls back to typing a token. Redirect URI: `https://<host>/auth/google/callback`.

**Entitlements (self-host):** device token → sha256 → `devices` → `families`. 401 unknown token; 402 `{error:"subscription"}` if not `active` or past `expires_at` (NULL = never); 429 `{error:"cap"}` once this IST month's `audio_s` ≥ `monthly_cap_s`; 429 `{error:"rate"}` over 20 turns/min. Audio seconds come from the byte count of a WAV that must be 16 kHz mono 16-bit (`wavSeconds`), never from the header's byteRate — a forged header would dodge the cap. Usage is recorded for every forwarded turn, success or not; Gemini retries count in `gemini_calls`, not in the family's minutes. The client speaks `LINES.subscription`/`LINES.cap` and the parent panel shows a Subscription card from `/api/me`.

**Setup wizard** (`openWizard` in `index.html`): home-screen hint (iOS Safari, not standalone) → consent → token (checked via `/api/me`, then consent POSTed; a failed POST blocks the step) → child → PIN ×2 → voice check (Enhanced/Premium detection) → mic check (AnalyserNode, `closeMic` after) → Guided Access. Settings are committed only on the last step. The app reopens the wizard whenever `settings.token`, `pinHash` or `consent` is missing; bump `CONSENT_VERSION` to re-ask every family.

**State lives only on the iPad**, in `localStorage` under `gappu:*` keys: `settings` (names, age, languages, minutes, token, PIN hash), `memories` (≤40 strings), `log` (≤300 turns, `alert` flag drives pink rows in parent view), `usage` (date + seconds today). `history` is in-memory per page load only. The server keeps no conversation state, only per-family counts in `data/gappu.db`.

**Response contract** (`SCHEMA` in worker, consumed by client): `heard`, `reply`, `lang` (`hi`|`en`), `mood` (one of `MOODS`, sets `body[data-mood]`), `new_facts` (≤2), `parent_alert` (bool). If you change the schema, update both `sanitizeOut` and the client's `sendAudio`.

**Gemini call quirks:** `askGemini` sends `thinkingConfig.thinkingLevel: "minimal"` first; a 400 triggers one retry without it (for models that don't support it). If a `lang: "hi"` reply contains no Devanagari (`romanHindi`), `handleChat` appends a corrective turn and asks once more — Roman-script Hindi is unreadable by the iPad's Hindi voice. Safety filters are `BLOCK_LOW_AND_ABOVE` on all four categories; a blocked or malformed response returns `fallback()` — with `parent_alert: true` for safety blocks, `false` for parse failures.

**Time limits** are enforced client-side: a 5 s interval accrues usage only while the tab is visible and there was interaction in the last 60 s; a 30-min gap resets the session counter. Hitting `sessionMinutes`/`dailyMinutes` triggers `goToSleep()`.

## Safety invariants

Keep these intact when editing:

- The Gemini key never reaches the client. Every `/api/chat` call must resolve to an active family (or match `APP_TOKEN` in single-token mode).
- The server stores counts only (turns, audio seconds, Gemini calls). Never audio, `heard`, `reply`, memories or alerts — that is the privacy pitch.
- `BLOCKED_FACT` regex in the worker rejects memories that look like PII (digits, addresses, school, phone, surname, Hindi equivalents). Memories are also capped (≤2 per turn, ≤40 total, ≤120 chars) on both sides.
- All user-supplied strings pass through `clean()` (strips control chars, trims, caps length) before reaching the prompt; `cleanProfile` clamps age to 2–12 and falls back to defaults.
- The system prompt's SAFETY section (dangerous objects → "ask Mummy or Papa", hurt/scared/secrets → `parent_alert: true`, no secrets from parents, never claim to be real) is the product. Edit wording carefully and re-run the README's "Test before Tosu uses it" checks after prompt changes.
- Replies are spoken aloud, so the prompt forbids emojis/lists/symbols; keep replies ≤35 words.
- Only the nickname is ever sent to Gemini — never a full name.

## iOS/Safari constraints baked into the client

- `speechSynthesis` only works after a user tap (`unlockTTS()` speaks an empty utterance on the button click).
- The mic (`AudioContext`) is closed after every turn (`closeMic`) so TTS plays at full volume.
- The app is meant to run as a Home Screen PWA under Guided Access; parent settings open via a long-press on the lock icon + PIN.
